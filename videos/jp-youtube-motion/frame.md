# Creative Direction

Field-architect authority rather than influencer spectacle. The motion should
explain hierarchy: identity first, system second, recommendation last.

## Do

- Use navy as the owner color, Azure blue as evidence, and gold as judgment.
- Build architecture paths in causal order.
- Use asymmetric frame zones and large editorial typography.
- Hold the final lockup long enough to read.
- Keep Spanish and English variants visually identical; only localized copy changes.
- Run transition-aware layout QA independently for every language.

## Do Not

- Do not use purple AI gradients, robots, particles, logo walls, or glitch.
- Do not imitate an official Microsoft brand package.
- Do not add narration, music, or decorative metrics to this sample.
